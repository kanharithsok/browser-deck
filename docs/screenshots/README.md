# Screenshots

All screenshots are captured from the running Electron app, including the native browser panes. They are saved at 1680 px wide for the README.

## Canvas dark

`canvas-dark.png` uses the dark theme with six iPhone 15 Pro viewports arranged in a horizontal row:

- Kuro Izakaya
- Golden Lantern
- Angkor Roasters
- Sala Books
- Phnom Burger
- Little Elephant Toys

## Canvas light with mixed viewports

`canvas-light-mixed-viewports.png` uses the light theme with one responsive pane, one tablet pane, and two phone panes:

- Forno Rosso (responsive)
- Butter & Crust (tablet)
- Borei Jewellery (iPhone 15 Pro)
- Mekong Motors (iPhone 15 Pro)

The overview is collapsed in both shots so it does not cover the rightmost pane. The demo sites were served locally during capture; the address bars therefore show `localhost:5173`.
